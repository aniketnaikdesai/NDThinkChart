NDThinkChart Quick Start
=========================

This is the short pointer. The canonical full guide is usage.md
(workflows, features, troubleshooting, change record pointer).

Start the app
-------------

Run from the project root:

    .venv/bin/python main.py

Headless (CI):

    QT_QPA_PLATFORM=offscreen .venv/bin/python main.py

Requirements
------------

1. Python virtual environment at .venv (Python 3.11):

    python3.11 -m venv .venv
    .venv/bin/pip install -r requirements.txt

   Packages: PyQt6, PyQt6-WebEngine (required - it hosts the chart;
   must match the installed PyQt6 version), ibapi-latest (provides the
   ibapi module), numpy, yfinance. There is no pyqtgraph dependency.

2. Interactive Brokers TWS Desktop installed, running, and logged in.

3. TWS API socket access enabled (TWS -> Edit -> Global Configuration
   -> API -> Settings):

    Host: 127.0.0.1
    Port: 7496
    Client ID: 1

   The app refuses to start on any other port. A paper (DU) TWS login
   on the same port works too; the badge shows amber "Paper".

4. Market data entitlements for the symbols being viewed (the app opens
   without them, but live charts and ticks need them).

Chart engine
------------

Lightweight Charts only. A leftover NDT_CHART_ENGINE value from an
older version is ignored.

Safety
------

- The app places, cancels and closes nothing. Orders happen in TWS.
- Read-Only API in TWS is recommended for extra safety.
